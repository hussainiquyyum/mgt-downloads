# TERM-LM

TERM-LM is a terminal workspace for coding agents. Run agents, shells, and tests in separate panes, keep them running while you detach, and pass work between agents.

- [Download the macOS beta](https://github.com/hussainiquyyum/term-lm-downloads/releases) for Apple Silicon or Intel.
- [Read the tester guide](GUIDE.md) to install TERM-LM and try a two-agent handoff.
- [Report a bug or request a feature](https://github.com/hussainiquyyum/term-lm-downloads/issues/new/choose).
- [Read the open-source attribution](NOTICE), [license](LICENSE), and [third-party notices](third-party/INDEX.txt).

# Multi-Agent Grid Terminal

MGT is a terminal workspace for coding agents. Run agents, shells, and tests in separate panes, keep them running while you detach, and pass work between agents.

- [Check macOS beta availability](https://github.com/hussainiquyyum/mgt-downloads/releases). Once published, the installer appears under **Assets**.
- [Read the tester guide](GUIDE.md) to install MGT and try a two-agent handoff.
- [Report a bug or request a feature](https://github.com/hussainiquyyum/mgt-downloads/issues/new/choose).
